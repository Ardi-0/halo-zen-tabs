# Halora privacy statement

Halora processes video pixels locally to create ambient light on YouTube and Twitch. It does not collect, store, or transmit video frames, browsing history, or personal information to an external service. The optional Sine mod receives compact edge-color strips inside the same browser to light Zen's tabs.

Settings are stored locally with `browser.storage.local`. A user can export settings to a local JSON file and import a chosen file. No account, analytics, advertising network, or remote server is used by the extension.

The extension requests access only to YouTube and Twitch pages and local extension storage. If future features change these practices, this statement and the extension's manifest disclosure must be updated before release.
