# Halora privacy statement

This public statement covers the Halora Firefox extension and its optional Halora Tabs for Zen Sine mod. The projects are distributed separately.

## Firefox extension

Halora reads pixels from the playing YouTube or Twitch video in the browser to draw an ambient halo. Frames are processed locally and are not stored or transmitted to an external service. The extension has no account, analytics, advertising network, or remote server.

Settings are kept in `browser.storage.local`. An export creates a local JSON file only when the user requests it; an import reads a file selected by the user. The extension requests access to YouTube and Twitch pages and local extension storage.

## Zen Sine mod

When enabled, the extension shares small, already-filtered edge-color strips and a dimming value with the Sine mod inside the same browser. The mod uses them to paint Zen's tab sidebar. It does not receive complete video frames or send data to a remote service.

If either component's data practices change, this statement and the extension's manifest disclosure will be updated before release.
